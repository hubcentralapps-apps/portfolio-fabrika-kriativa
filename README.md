# Site Fábrika Kriativa

Site institucional estático, pronto para GitHub Pages.

## Publicação
1. Envie `index.html` e a pasta `assets` para a raiz do repositório.
2. Faça commit.
3. Em **Settings → Pages**, selecione **Deploy from a branch**.
4. Branch: `main`.
5. Folder: `/(root)`.
6. Salve.

## Domínio
Para usar `fabrikakriativa.com.br`, configure o domínio personalizado em **Settings → Pages → Custom domain** e depois ajuste o DNS na Hostinger.
