# Fábrika Kriativa — Portfólio Web V2

Versão responsiva e editorial do portfólio 2026, pronta para GitHub Pages.

## Publicar
1. Crie um repositório no GitHub.
2. Envie `index.html`, `.nojekyll` e a pasta `assets`.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a URL do GitHub Pages aparecer.

## Estrutura
- `index.html`: site completo
- `assets/photos/`: imagens otimizadas usadas no layout
- `.nojekyll`: evita processamento Jekyll desnecessário
